# 📖 Bond Futures Lab 대시보드 — 사용자 메뉴얼 (읽는 법)

> 대상: `frontend/sim_dashboard.html` · 최초 작성 2026-08-26
> 이 문서만 읽으면 화면을 처음 보는 사람도 5분 안에 다 읽을 수 있습니다.

## 1. 이 화면이 뭐예요? (3줄)

1. 채권 선물 **두 개의 가격 차이(spread)** 를 1분마다 기록해서 보여주는 화면이에요.
2. 그 차이가 **평소보다 많이 벌어지면** 색과 숫자로 알려줘요.
3. 다만 지금은 **보기만 하는 단계**예요 — 자동 주문 기능이 없고, 통계가 "아직 믿을 만하지 않다"고 말하고 있어요.

## 2. 화면 구조 — 무엇이 어디 있나

맨 위에 **탭 두 개**가 있어요. 탭이 곧 "무엇과 무엇을 비교하는가"예요.

| 탭 | 비교 대상 | 언제 보나 |
| --- | --- | --- |
| 🇰🇷 **KTB3 − KTB10** | 한국 국채선물 3년 vs 10년 | 한국 시장 안에서의 차이를 볼 때 |
| 🇰🇷🇺🇸 **KTB10 − ZN** | 한국 10년 vs 미국 10년 | 한·미 금리 차이를 볼 때 (원래 목표 pair) |

탭을 누르면 주소 끝이 `#ktb` / `#kus` 로 바뀌어서, 그 주소를 그대로 복사해 주면 상대도 같은 탭을 봐요.

탭 **안쪽**은 항상 같은 순서예요.

| 구역 | 제목 | 무엇을 보나 |
| --- | --- | --- |
| A | 지금 이 pair 는 어떤 상태인가요 | 숫자 카드 4개 — 지금 차이 / 평소 대비 / 되돌아오는 속도 / 증거 세기 |
| B | 차이가 얼마나 벌어졌나 | 그림 2개 — 위는 spread, 아래는 z-score |
| C | 표본이 어떻게 끊겨 있나 | 데이터가 몇 조각으로 끊겨 있는지 (세션) |
| D | 판정 일지 / 못 하는 것 | 왼쪽 탭은 날짜별 판정 변화, 오른쪽 탭은 아직 안 된 것 목록 |
| E | 시뮬레이션 결과 | (왼쪽 탭만) 가짜 매매를 돌려본 결과 |

탭 **아래쪽**은 두 탭이 공유해요: `0 읽는 법` · `1 상품` · `2 알고리즘` · `3 Formal Definition`(수식).

## 3. 색깔·표기 뜻

| 표시 | 뜻 |
| --- | --- |
| 🟢 초록 알약 | 조건을 만족함 (예: 진입 게이트 통과) |
| 🟠 노랑 알약 | 주의 / 아직 조건 미달 |
| 🔴 빨강 | 고장 나 있거나 아예 안 되는 것 |
| **노란 점선** (위 그림) | 그 구간의 평균 — "평소 자리" |
| **붉은 띠** (아래 그림) | ±2σ 진입선. 주황 선이 이 띠에 들어가면 "많이 벌어졌다" |
| 왼쪽에 노란 세로줄이 있는 박스 | 한계·주의 사항. **여기를 꼭 읽어야 해요** |
| `▸` 로 시작하는 줄 | 눌러서 펼치는 상세 (수식) |

## 4. 용어 사전

| 용어 | 원래 말 | 쉬운 뜻 |
| --- | --- | --- |
| spread | 스프레드 | 두 선물 가격의 차이. 이 화면이 보는 대상 |
| z-score | 표준화 점수 | 평소(최근 2시간)보다 몇 σ 벗어났나. ±2 부터 "많이 벌어졌다" |
| σ (시그마) | 표준편차 | "보통 이 정도는 움직인다"는 폭 |
| half-life | 반감기 | 벗어난 거리의 **절반**이 돌아오는 데 걸리는 시간. 짧을수록 고무줄이 셈 |
| ADF p | 정상성 검정 | "정말 되돌아오나?" 시험 점수. **0.05보다 작아야 합격** |
| t_HAC | 보정된 증거 세기 | "벌어지면 돌아온다"의 증거. **−1.64보다 작아야 게이트 통과** |
| 게이트 | 진입 자격 | 통계 증거가 충분할 때만 열리는 자물쇠. 닫혀 있으면 그날은 거래 안 함 |
| 세션 | session | 장이 열려 있는 한 덩어리. 주간 09:00~15:45 · 야간 18:00~05:00 |
| 1 pt | 1포인트 | KTB 선물 1계약 기준 **100만원** |
| ×100 | 로그 가격비 | 통화가 다른 pair(KTB10−ZN)에서 쓰는 단위 없는 척도. 1 ≈ 1% |
| KTB3/10/30 | 한국 국채선물 | 국고채 3년·10년·30년 선물 (KRX) |
| ZT/ZF/ZN/ZB/TN | 미국 국채선물 | 2년·5년·10년·30년·Ultra 10년 (CME) |

## 5. 자주 묻는 질문

**Q. 왼쪽 탭은 그냥 빼기인데 오른쪽 탭은 왜 로그를 쓰나요?**
KTB10은 **원화** 액면, ZN은 **달러** 액면이에요. `105.65 − 108.69` 처럼 그냥 빼면 원화와 달러를 섞어 빼는 셈이라 뜻이 없어요. 그래서 단위가 없어지는 **로그 가격비**를 씁니다.

**Q. 숫자가 어제와 다른데요?**
데이터가 쌓이면서 통계가 흔들려요. **그 흔들림 자체가 "아직 판정할 때가 아니다"라는 신호**예요. D구역(판정 일지)이 바로 그 흔들림을 기록하는 곳입니다.

**Q. "게이트 통과"면 사도 되나요?**
아니요. 게이트는 **세 자물쇠 중 하나**일 뿐이고, 지금 이 실험실은 **주문 기능 자체가 없습니다**. 표본도 며칠치라 어떤 수치도 대외 인용 금지입니다.

**Q. 그림의 선이 뚝 끊기지 않고 이어져 있는데, 장 마감을 건너뛴 건가요?**
⚠️ 네 — **현재는 세션 경계를 넘어 선이 이어져 그려집니다.** 통계 계산(z·half-life·t_HAC)은 세션 경계를 넘는 쌍을 **버리지만**, 그림은 아직 끊어 그리지 않습니다. 15:45 마감과 18:00 개장 사이의 가격 점프가 실제보다 부드럽게 보일 수 있습니다. (개선 예정)

**Q. 데이터에 구멍이 있나요?**
있습니다. C구역(세션)을 보면 조각이 몇 개인지 나와요. 조각이 많다는 건 수집이 끊겼다는 뜻입니다.

**Q. 화면을 새로 만들려면?**
```bash
python tools/build_lab_dashboard.py      # frontend/sim_dashboard.html 갱신
python -m http.server 8777 -d frontend   # http://127.0.0.1:8777/sim_dashboard.html
```
`file://` 로 직접 열어도 되지만, 브라우저에 따라 한글이 깨질 수 있어 로컬 서버를 권합니다.
