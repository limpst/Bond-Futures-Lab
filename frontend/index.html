① 아래 시그널 표가 심장이에요 — pair 마다 "지금 스프레드가 평소보다 얼마나 벌어졌나(z)"를 보여줘요. |z|≥2 이고 게이트(IQR·ECM)를 통과하면 시그널이 켜져요. ② 차트는 두 상품을 시작=100 으로 맞춘 비교 가능한 수치예요 — 벌어졌다 좁혀지는 모양이 이 전략이 먹는 것. ③ 주문은 기본 dry(가상 기록) — 실계좌 전환은 CLI 글로벌 스위치 + RMS 연결 후에만 가능해요. 데이터가 없으면 "insufficient" 로 정직하게 표시돼요. 이 페이지는 python -m http.server 로 프로젝트 루트에서 열어야 데이터를 읽어요.

pairbarsβzIQR 위치 ECM γECM tlead-lag(봉)시그널비중
